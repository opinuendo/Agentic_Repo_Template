# docs/

| Directory or file | What it holds |
|---|---|
| [`next-steps.md`](next-steps.md) | What is open right now; where a new session starts |
| [`adr/`](adr/) | Decisions made, one file each, never changed after acceptance |
| [`proposals/`](proposals/) | Designs not yet decided; they authorize no code |
| [`conventions/`](conventions/) | How we do things, each citing its ADR |

Add `onboarding/`, `domain/` (glossary and business rules), or other directories as the repo needs
them, each with its own README.
