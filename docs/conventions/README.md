# docs/conventions/ — how we do things

Each convention is the practical "how" for a decision recorded in [`docs/adr/`](../adr/). Every page
names the ADR it applies; the reasoning stays in the ADR, not here.

| Convention | Applies |
|---|---|
| [`commits.md`](commits.md) | ADR-0002 (layered commits), ADR-0004 (what agents may do in git) |

Add a page when a convention needs more than a line in `AGENTS.md`. If a convention has no ADR to
cite, write the ADR first.
